# NewQC Frontend

فرانت‌اند فارسی و راست‌به‌چپ با React، TypeScript و Vite. شامل داشبورد، فهرست قابل فیلتر تماس‌ها، جزئیات ارزیابی و حالت‌های صف/خطا است.

## اجرای محلی

```sh
npm install
npm run dev
```

آدرس اعلام‌شده توسط Vite را باز کنید. برای بررسی خروجی انتشار:

```sh
npm run build
```

ورود، خواندن هویت و تغییر رمز به API موجود متصل شده‌اند؛ بک‌اند باید توسط کاربر روی پورت ۸۰۰۰ اجرا شود. راهنمای بررسی در docs/LOCAL_AUTH_CHECK_FA.md است. توکن فقط در حافظه است؛ Refresh ورود مجدد می‌خواهد.

داشبورد نمودارمحور، تماس‌ها، جزئیات و تاریخچهٔ ارزیابی و عملکرد کارشناسان به API واقعی متصل‌اند. داشبورد به‌طور پیش‌فرض ۳۰ روز اخیر را نشان می‌دهد؛ بازهٔ دلخواه و همهٔ زمان‌ها نیز قابل انتخاب‌اند. نمونهٔ طراحی از صفحهٔ ورود جداگانه در دسترس است و دادهٔ ساختگی دارد. هیچ فایل بک‌اند تغییر نکرده است.

برای بررسی تست‌ها: `node --test tests/*.test.mjs`.

تصمیم‌ها و نقشهٔ راه در پوشهٔ docs نگهداری می‌شوند.
