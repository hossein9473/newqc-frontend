# NewQC Frontend

نمونهٔ تعاملی فارسی و راست‌به‌چپ با React، TypeScript و Vite. شامل داشبورد، فهرست قابل فیلتر تماس‌ها، جزئیات ارزیابی و حالت‌های صف/خطا است.

## اجرای محلی

```sh
npm install
npm run dev
```

آدرس اعلام‌شده توسط Vite را باز کنید. برای بررسی خروجی انتشار:

```sh
npm run build
```

ورود، خواندن هویت و تغییر رمز به API موجود متصل شده‌اند؛ بک‌اند باید توسط کاربر روی پورت ۸۰۰۰ اجرا شود. راهنمای بررسی در docs/LOCAL_AUTH_CHECK_FA.md است. توکن فقط در حافظه است؛ Refresh ورود مجدد می‌خواهد.

نمونهٔ طراحی از صفحهٔ ورود در دسترس است و دادهٔ ساختگی دارد؛ گزارش‌های حساب واقعی هنوز متصل نشده‌اند. جزئیات ارزیابی نمونه‌اند و با نمرهٔ کلی تماس محاسبهٔ واقعی تشکیل نمی‌دهند. هیچ فایل بک‌اند تغییر نکرده است.

تصمیم‌ها و نقشهٔ راه در پوشهٔ docs نگهداری می‌شوند.
